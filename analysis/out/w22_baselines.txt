== F. Leak audit

(source cells: training loss and source validation), and no other code names a label file. Target labels are read only inside
src/xcell_gnn.evaluate(). PANDA and GENIE3 inputs, and scRegNet node features and graph, are built under xcell_gnn.no_labels(), which
raises on any read of Train_set.csv / Test_set.csv / Label.csv / BL--network.csv; run_scr asserts the target is not a source.
